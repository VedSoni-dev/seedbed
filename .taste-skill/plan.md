h1: Flower hover effect for your website

features h2: What seedbed draws and ships. <muted>Every flower grows on one canvas, from about 470 lines of JavaScript.</muted>
 - Grows a stem, then leaves, then the flower / Each dot grows on its own delay and wilts back in the same order.
 - Grows the garden under a finger on phones / Touch drag works like a cursor. With reduced motion, flowers open at once.
 - Turns a sentence into a style / Describe a mood and AI picks the petals, stems and paper colour.
 - Copies as a web component or React / The code comes with your settings in it, ready to paste.
statement: One file, any website / seedbed.js is one file with no dependencies. It loads nothing and sends nothing, so it runs in plain HTML, React, Vue, Svelte or a Webflow embed.

 - Add the script / Save seedbed.js beside your page and load it as a module.
 - Place the tag / Give seedbed-garden a height. It fills its box.
 - Set the style / preset, radius, wilt-delay and density are plain attributes.
