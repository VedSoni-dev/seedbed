What works

Grow, then wilt

Stem, then leaves, then the flower opens. After the pointer leaves they wilt in the same order, leaving a comet tail.

Five styles, live

Meadow, Tulip, Lavender, Ink and Night. The sun button flips to night.

Drawn in code

Cosmos, daisy, tulip and lavender heads are procedural. Nothing is traced.

Tune everything

Radius, stem height, speed, wilt delay, density, spacing and seed, all live.

Copy it

A web component, a React file or a one-line CDN tag, with your settings baked in.

Phones and calm

Touch drag works. With reduced motion, blooms are instant and calm. It sleeps when idle or offscreen.

Not yet

  • No npm package yet: copy the file or use the CDN tag.
  • No export to video or image.
  • No share links for a garden's settings.
  • No Vue or Svelte wrappers (the custom element works there).
  • Not on publik yet (new listings are capped each week), so the app opens with no sign-in.

Run it yourself

<script type="module" src="./seedbed.js"></script>
<seedbed-garden preset="tulip" radius="160" style="height:320px"></seedbed-garden>

Or run the app: git clone https://github.com/VedSoni-dev/seedbed, then npm install && npm run dev. MIT licensed.
